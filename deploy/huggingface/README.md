# Spellforge

A turn-based roguelike where you invent spells in plain English and a team of AI agents
(Designer, Balancer, Coder, Artist, Tester) designs, balances, codes, tests and hot-loads
them into the running game.

This Space is deployed automatically from GitHub; the source, architecture and evals live
there: https://github.com/GiampaoloConti/spellforge

Playing needs an invite code.
